## 使い方

1. 「変換の向き」で「YAML → JSON」か「JSON → YAML」を選びます。
2. 入力欄にデータを貼り付けるか、`.yaml` / `.yml` / `.json` ファイルをドラッグ&ドロップします。
3. 変換結果が出力欄に表示されます。「コピー」または「ダウンロード」で取り出せます。

Docker Compose や GitHub Actions、Kubernetes の設定ファイルを JSON で確認したいとき、API の JSON を読みやすい YAML にしたいときなどに便利です。

## 変換のルール

- YAML 1.2 の規則で読み込みます。`2026-09-25` のような日付に見える値や `yes` / `no` は文字列のまま扱います（`true` / `false` だけが真偽値になります）。
- `---` で区切った複数の文書は、JSON の配列にまとめます。
- `12345678901234567890` のような大きな整数も、桁を落とさずに変換します。
- JSON → YAML では、`"true"` や `"123"` のように YAML では別の意味になる文字列を、引用符で囲んで文字列のまま保ちます。
- YAML のコメント（`#`）は JSON に持ち越せないため、変換すると消えます。

## 構文エラーの表示

YAML として正しくない場合は、エラーの位置（行・列）と内容を表示します。インデントのずれ（タブ文字の混入を含む）や、`[` `{` の閉じ忘れがよくある原因です。

## よくある質問

**Q. 入力した設定ファイルは送信されますか？**
A. いいえ。変換はすべてお使いのブラウザ内で行われ、データはサーバーへ送信・保存されません。パスワードなどを含む設定ファイルも安心して変換できます。

**Q. アンカーとエイリアス（`&` と `*`）は使えますか？**
A. 使えます。参照先の内容を展開して JSON にします。ただし、展開を悪用して処理を止めるような極端な入力は、安全のため変換を中止します。
