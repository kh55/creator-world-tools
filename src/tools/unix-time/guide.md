## 使い方

- **タイムスタンプ → 日時**: `1700000000` のような UNIX タイムスタンプを入力すると、選択したタイムゾーン・UTC・ISO 8601 形式の日時と、現在からどれくらい前（後）かを表示します。
- **日時 → タイムスタンプ**: `2026-09-25 12:34:56` のように日時を入力すると、秒とミリ秒のタイムスタンプを表示します。時差の指定がなければ、選択したタイムゾーンの時刻として読み取ります。
- 「現在時刻を入れる」で、両方の欄に今の時刻が入ります。

選択したタイムゾーンはブラウザに保存され、次回も同じ設定で使えます。

## 秒・ミリ秒の自動判定

UNIX タイムスタンプは、システムによって単位が異なります。桁数から単位を自動で判定します。

| 桁数の目安 | 判定 | よく使われる場所 |
|---|---|---|
| 10 桁 | 秒 | Unix / Linux、PHP、Python の `time.time()` |
| 13 桁 | ミリ秒 | JavaScript の `Date.now()`、Java |
| 16 桁 | マイクロ秒 | PostgreSQL、Python の一部 |
| 19 桁 | ナノ秒 | Go の `UnixNano()` |

小数（`1700000000.5`）や、1970 年より前を表す負の値にも対応しています。

## 入力できる日時の形式

- `2026-09-25 12:34:56` / `2026/09/25 12:34:56`（秒は省略可）
- `2026-09-25`（その日の 0 時）
- `2026-09-25T03:34:56Z` / `2026-09-25T12:34:56+09:00`（時差つき。タイムゾーンの選択より優先します）

## タイムゾーンと夏時間

アメリカやヨーロッパなど夏時間のある地域を選ぶと、その日時に有効な時差（例: ニューヨークは夏 -04:00、冬 -05:00）で計算します。夏時間の切り替えで存在しない時刻や 2 回ある時刻は、ブラウザの計算に従います。

## よくある質問

**Q. UNIX 時間とは何ですか？**
A. 1970 年 1 月 1 日 0 時 0 分 0 秒（UTC）からの経過秒数です。タイムゾーンに関係なく世界共通の値なので、プログラムやデータベースで日時を記録するのによく使われます。

**Q. 入力した値は送信されますか？**
A. いいえ。変換はすべてお使いのブラウザ内で行われます。
